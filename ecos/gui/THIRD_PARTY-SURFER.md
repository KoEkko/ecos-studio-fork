# Third-party: Surfer (waveform viewer)

SimDebug embeds **[Surfer](https://surfer-project.org/)** for RTL waveform viewing (VCD, FST, GHW).

- **Bundled assets:** `public/surfer/` — web build from GitLab CI job `pages_build` on branch `main` (see `openspec/changes/sim-debug-waveform-surfer/SURFER-INTEGRATION-OPERATIONS.md` for provenance).
